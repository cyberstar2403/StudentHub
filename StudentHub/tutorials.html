HTMLBeginner
◷ 15 min

Create your first web page

Build a small HTML document with a title, headings, paragraphs, and a meaningful link.

Step-by-step

Start with , add a language attribute to the html element, and include a head and body. Use one clear h1 for the page title, then organise sections with h2 headings. Save the file as index.html and open it in a browser.

Remember: Semantic HTML describes the meaning of content. Prefer elements such as main, nav, article, and footer when they fit.

STUDY SKILLSBeginner
◷ 20 min

Turn a lecture into useful notes

Move from hurried transcription to notes you can actually review.

Step-by-step

Before class, write the topic and two questions you want answered. During class, capture key ideas, examples, and questions rather than every sentence. Within a day, rewrite the main points in your own words and add a short self-test.

Remember: The goal is retrieval: close your notes and try to explain the concept without looking.

JAVASCRIPTBeginner
◷ 12 min

Make a button interactive

Use a click event to update a message on the page.

Step-by-step

Add a button with an id and a paragraph with an id. In JavaScript, select both elements with querySelector. Attach addEventListener('click', ...) to the button, then update the paragraph textContent inside the callback.

Remember: Keep behaviour in JavaScript and content structure in HTML. This separation makes projects easier to maintain.

PRODUCTIVITYBeginner
◷ 18 min

Create a realistic weekly study plan

Turn deadlines and available time into a manageable weekly routine.

Step-by-step

List fixed commitments first. Add deadlines and estimate the work required. Break large tasks into 30–60 minute blocks, leave buffer time, and choose one priority for each session. Review the plan at the end of the week.

Remember: A plan is a guide, not a test. Adjust it when your workload or energy changes.
